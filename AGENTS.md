# Project instructions

## Scope

This repository is an intentionally minimal Codex Cloud workspace. Do not introduce an application framework, package manager, service, or deployment configuration until the requested project requires one.

## Working rules

- Inspect the repository before making changes and preserve existing work.
- Keep changes focused on the requested outcome.
- Do not add, expose, or commit secrets. Use Codex Cloud environment variables or network secrets when a task needs access to an external service.
- Run the most relevant available checks before reporting completion. State clearly when no automated verification exists.
- Update `README.md` when adding a project, its setup steps, or its verification command.
